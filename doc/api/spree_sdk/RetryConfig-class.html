RetryConfig

RetryConfig class

Conservative retry policy for the Spree SDK (ADR-003).

Defaults: safe/idempotent reads only, at most maxRetries retries with exponential backoff plus jitter, honoring Retry-After. Mutations (POST/PUT/PATCH/DELETE) are retried only when RetryConfig observes explicit idempotence — i.e. the request carries an idempotency key (RequestOptions.idempotencyKey, sent as Idempotency-Key, a server-supported mechanism per docs/research/store-api-contract.md section 4).
