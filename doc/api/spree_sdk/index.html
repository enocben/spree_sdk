Constants

redactedPlaceholder → const String
Placeholder substituted for secret values.
safeHttpMethods → const Set<String>
HTTP methods considered safe (and therefore idempotent) for automatic retries. Everything else is a mutation and is never retried without explicit idempotence (AGENTS.md sections 3.9 and 6, ADR-003).
sensitiveHeaderNames → const Set<String>
Header names (compared lower-cased) whose values are always secrets.
sensitiveQueryParameters → const Set<String>
Query parameter names (compared lower-cased) treated as secrets.
