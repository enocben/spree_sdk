Applies store credit (POST /carts/{id}/store_credits).

amount is a decimal string (never a number); omitting it applies the maximum usable credit (verified contract §4, SRC 819).

Implementation

Future<Cart> applyStoreCredit(
  String cartId, {
  String? amount,
  RequestOptions? options,
}) async {
  final Map<String, Object?> body = <String, Object?>{};
  if (amount != null) {
    body['amount'] = amount;
  }
  final Object? json = await _client.request(
    'POST',
    '/carts/${Uri.encodeComponent(cartId)}/store_credits',
    body: body,
    options: options,
  );
  return Cart.fromJson(_asMap(json));
}
