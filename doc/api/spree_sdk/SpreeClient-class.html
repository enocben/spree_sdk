SpreeClient

SpreeClient class

Entry point for the Spree Store API (frozen contract, docs/architecture/file-ownership.md table 2).

final client = SpreeClient(
  baseUrl: Uri.parse('https://api.mystore.com'),
  publishableKey: 'pk_xxx',
);
final products = await client.requestPaginated(
  'GET',
  '/products',
  query: const ListQuery(limit: 25).toQueryParameters(),
  fromJson: (item) => item as Map<String, Object?>,
);
client.close();

The client owns its transport lifecycle (close releases resources), holds no ambient auth/cart state, and never persists credentials.
