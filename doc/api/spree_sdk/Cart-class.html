Cart class

The active cart (checkout in progress).

Source: packages/sdk/src/types/generated/Cart.ts; SPEC store.yaml#/components/schemas/Cart. checkout_steps / state_lock_version appear only in the TS-SDK mocks (tests/mocks/handlers.ts, per contract §4) — not in the serializer type or the SPEC — so they are not modeled here (Limitation).
