Fetches one completed order.

GET /orders/{id} (verified: SPEC path, SRC 853). Returns an Order, or an OrderGroup when the checkout reached several sellers — narrow the result with isOrderGroup, exactly as carts.complete answers. Accepts the cart id the checkout was placed from in place of the order id. Auth: JWT or guest spreeToken.

Implementation

Future<Object> get(
  String id, {
  List<String>? expand,
  List<String>? fields,
  RequestOptions? options,
}) async {
  final Object? json = await _client.request(
    'GET',
    '/orders/$id',
    query: ListQuery(expand: expand, fields: fields).toQueryParameters(),
    options: options,
  );
  if (json is Map<String, Object?> && isOrderGroup(json)) {
    return OrderGroup.fromJson(json);
  }
  return Order.fromJson(json as Map<String, Object?>);
}
