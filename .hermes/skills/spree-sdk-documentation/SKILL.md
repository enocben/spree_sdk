# SDK Documentation Skill

## Documentation requirements
Document installation, minimum Dart SDK, tested Flutter versions, initialization, base URL, auth/token provider, resources, pagination, errors, retries, platform support, and limitations.

Provide runnable pure-Dart and Flutter examples. Every documented method must exist in public exports and be backed by tests. Explain what the SDK does not do, especially credential persistence and payment-card handling.

## Release docs
Maintain README, CHANGELOG, API docs, examples, and publishing checklist. Verify package name availability, license, dependencies, package contents, and `dart pub publish --dry-run`. Never publish without explicit owner approval.
