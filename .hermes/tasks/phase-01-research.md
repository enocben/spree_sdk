# Phase 01 — Research

Owner: orchestrator. Delegate to API analyzer and architect.

- Inspect upstream SDK source, tests, exports, package metadata and release history.
- Verify Store API docs/OpenAPI and record API version, commit/tag, inspection date.
- Produce inventory, API contract, auth flows, feature parity matrix, and open questions.
- Mark facts verified/inferred/unknown with evidence.
- No implementation code in this phase.
- Gate: owner approves scope, parity matrix and target API version.
